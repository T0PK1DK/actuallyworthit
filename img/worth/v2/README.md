# Worth — expression set v2

Thirteen poses cut from the character sheet, transparent background, 440px tall
(hero is 760px). The outside is transparent; Worth's body stays opaque white, so
he sits correctly on both the paper and dark grounds.

## Semantic mapping

Worth marks **judgment moments**. He is the verdict voice, not decoration — if a
spot is not making or qualifying a call, he does not belong there.

| Pose | Use |
|---|---|
| `neutral` | masthead brand mark; default |
| `waving` | page/section welcome |
| `shrug` | **DEPENDS** verdict |
| `thumbs-up` | **WORTH IT** verdict |
| `unimpressed` | **SKIP** verdict; a principled refusal |
| `skeptical` | manufacturer claims we did not verify |
| `thinking` | methodology, trade-offs, evidence grade |
| `curious` | "not listed" / no confirmed ASIN |
| `surprised` | empty state |
| `pleased` | footer sign-off |
| `cheering` | a rare unqualified win |
| `smitten` | top pick (unused so far — no page earns it) |
| `hero` | large brand moments |

## Relationship to the existing set

The six files in the parent directory (`judge-skeptical`, `neutral-gutter`,
`shrug-depends`, `thinker-tradeoffs`, `unimpressed-skip`, `worth-it-conditional`)
are the older, rougher drawings still referenced by the live review pages. This
set is a drop-in upgrade but is kept separate so nothing changes on the live site
until someone decides to swap it.
